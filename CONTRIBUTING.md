# Contributing to Pavu Labs projects

Thank you for contributing. Check the target repository's own contribution guide first; repository-specific instructions take precedence over this default.

Keep changes focused, document security and privacy effects, and add tests proportional to the risk. Clearly distinguish among behavior that is implemented, behavior that has been verified, and behavior that still requires platform permissions or real-device validation.

Use pull requests for changes to the default branch. Never commit credentials, signing material, provisioning profiles, private keys, user telemetry, or sensitive logs. Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

By contributing, you confirm that you have the right to submit the material and agree to the license of the target repository. Participation is governed by our [Code of Conduct](CODE_OF_CONDUCT.md).
