# Security Policy

Please report suspected vulnerabilities privately through the affected repository's **Security** tab and GitHub private vulnerability reporting. Do not disclose exploit details, sensitive logs, credentials, user activity, or personal data in a public issue.

A useful report includes:

- the affected repository, commit, component, and platform;
- required privileges and preconditions;
- potential confidentiality, integrity, availability, privacy, or detection-bypass impact;
- minimal reproduction steps; and
- a suggested mitigation, when available.

Pavu Labs will acknowledge complete reports, investigate them, and coordinate disclosure after a fix is available. Testing must not access data beyond what is necessary to demonstrate the issue, disrupt third-party systems, or impair service availability.
